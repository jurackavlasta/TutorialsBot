Understanding Decorators

What are Decorators?

In Python, decorators are a powerful tool that allow you to modify the behavior of a function or a class. They enable code reuse and can enhance the functionality of existing code without altering its structure.

Creating a Simple Decorator

Here’s a basic example of a decorator that prints the arguments of a function:

def decorator_function(original_function):
        def wrapper_function(*args, **kwargs):
            print(f'Arguments were: {args}, {kwargs}')
            return original_function(*args, **kwargs)
        return wrapper_function

    @decorator_function
    def display_info(name, age):
        print(f'Display Name: {name}, Age: {age}')

    display_info('John', 30)

In this example, the decorator prints arguments passed to the display_info function.

Using Generators for Efficient Data Handling

What are Generators?

Generators are a special type of iterator that allow you to iterate over data without storing the entire dataset in memory. This is highly beneficial for working with large datasets.

Creating a Generator

Create a generator function using the yield keyword:

def count_up_to(max):
        count = 1
        while count <= max:
            yield count
            count += 1

    counter = count_up_to(5)
    for number in counter:
        print(number)

The count_up_to function generates a sequence of numbers up to a given maximum.

Context Managers for Resource Management

Understanding Context Managers

Context managers are a great way to manage resources such as file streams or network connections. They ensure that resources are properly allocated and released, making your code cleaner and more reliable.

Using the with Statement

Python’s with statement simplifies exception handling by encapsulating common preparation and cleanup tasks:

with open('file.txt', 'r') as file:
        content = file.read()

This automatically closes the file after the block inside with is executed.
