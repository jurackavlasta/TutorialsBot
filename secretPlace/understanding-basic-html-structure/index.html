Understanding Basic HTML Structure

Introduction to HTML Structure

HTML, or HyperText Markup Language, is the standard markup language for creating web pages and web applications. Understanding the basic structure of HTML is crucial for anyone interested in web development or design. This tutorial will guide you through the essential elements of a well-structured HTML document.

What is HTML?

HTML defines the meaning and structure of web content. It consists of a series of elements, or tags, that tell the browser how to display text, images, and other media. Each HTML document has a specific structure that you must follow to ensure your webpage displays correctly.

Basic HTML Document Structure

Every HTML document consists of several key components:

  • Document Type Declaration (): This tells the browser which version of HTML the page is using.
  • HTML Element (): The root element that wraps all content on the page.
  • Head Section (): Contains meta-information about the document, including the title, character set, and links to stylesheets and scripts.
  • Body Section (): This is where all visible content on the page is placed, including text, images, and multimedia.

Example of a Basic HTML Document

<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>My First Page</title>
    </head>
    <body>
        <h1>Welcome to My Page!</h1>
        <p>This is a paragraph of text on my first HTML page.</p>
    </body>
</html>
